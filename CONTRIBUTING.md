# Development Guide

## Module Ownership
Each team member should confirm their assigned module before coding.

## Integration
Coordinate shared database models, API contracts, authentication,
environment variables, and common UI components with the team.

## Git Workflow
1. Start from the latest main branch.
2. Create a feature branch for your assigned module.
3. Commit changes using clear messages.
4. Push the branch to GitHub.
5. Open a Pull Request into main.
6. Request review before merging.

Do not push directly to main.
